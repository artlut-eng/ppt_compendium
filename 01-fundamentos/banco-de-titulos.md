# Banco de títulos-conclusão

O título é a parte do slide que mais define a qualidade percebida. Este banco traz fórmulas, pares "ruim → bom" por tipo de deck, variações por estilo do decisor e vocabulário a evitar. Teste sempre: lendo só os títulos em sequência, a história se sustenta?

## Fórmulas que funcionam
| Fórmula | Exemplo |
|---|---|
| **Resultado + causa** | "Vendas cresceram 12% no Q3, puxadas pelo Sul" |
| **Apesar de X, Y** | "76% das solicitações estão atrasadas, apesar de 4,3% de saving" |
| **X, mas Y** | "Contrato vigente reduz atraso, mas ainda opera longe do ideal" |
| **Onde está o problema** | "O maior tempo controlável está após a emissão do pedido" |
| **Negação de uma crença** | "A criticidade declarada não está protegendo o prazo" |
| **Ainda não** | "A melhora recente ainda não prova uma virada sustentável" |
| **Número + implicação** | "15 marcos no último trimestre exigem acompanhamento mensal" |
| **Pedido com prazo** | "Precisamos aprovar o plano B até sexta" |
| **Quantidade + verbo forte** | "Três decisões destravam a próxima etapa" |
| **Condição** | "A carteira pode gerar mais valor com os mesmos recursos" |
| **Comparação** | "Sudeste responde por todo o gap da meta" |
| **Tendência com ressalva** | "Receita cresce pelo 5º trimestre, mas a margem caiu 3 p.p." |

Regras: frase completa com verbo; um número quando houver; no máximo 2 linhas (cerca de 90 caracteres); sem dois pontos no fim; sem "Overview", "Análise", "Status", "Dados" sozinhos.

## Vocabulário
| Evitar | Preferir |
|---|---|
| Sinergia, alavancar, robusto, inovador, disruptivo | o ganho concreto ("reduz 15% do custo") |
| Otimizar, melhorar (sem número) | reduzir/aumentar X em Y |
| Overview, análise, status, dados, considerações | a conclusão |
| "Uma possibilidade seria", "talvez" | "Recomendamos", "Propomos" |
| Aproximadamente, cerca de (em título) | o número com 1 casa |
| Diversos, vários | o número |
| Alinhar (como ação) | decidir X, aprovar Y, definir Z |
| Intensificar, reforçar (sem objeto) | a ação com dono e prazo |
| Mundo VUCA, novo normal, jornada | (omitir) |

## Verbos úteis por natureza
- **Fato**: cresceu, caiu, concentra, responde por, ficou, atingiu, consumiu.
- **Inferência**: sugere, indica, aponta, explica, ainda não prova.
- **Recomendação**: propomos, recomendamos, precisamos, deve, exige.
- **Decisão pedida**: aprovar, confirmar, autorizar, definir, priorizar.
