# Glossário

| Termo | Significado neste compêndio |
|---|---|
| **Deck** | O arquivo de apresentação completo (.pptx) |
| **Spec** | Descrição estruturada (JSON) do deck, usada pelo código gerador. Ver `schemas/` |
| **Modelo de slide** | Padrão reutilizável de um único slide (ex.: `kpi-dashboard`) |
| **Título-conclusão** | Título de slide escrito como frase afirmativa com a mensagem principal |
| **Sumário executivo** | Slide (ou 2) no início com a resposta completa para quem só lê o começo |
| **Estratégico / Tático / Operacional** | Níveis de decisão: direção (anos) / gestão (meses) / execução (dias) |
| **SCQA** | Situação, Complicação, Questão, Resposta — estrutura de abertura (Minto) |
| **Pirâmide de Minto** | Resposta primeiro, depois argumentos agrupados, depois dados |
| **KPI** | Indicador-chave de desempenho |
| **Semáforo (RAG)** | Código de status Vermelho / Amarelo / Verde (Red / Amber / Green) |
| **Zona segura** | Área do slide dentro das margens onde conteúdo pode ser colocado |
| **Paleta** | Conjunto nomeado de cores: primária, secundária, destaque, neutros, semânticas |
| **OEE** | Overall Equipment Effectiveness — disponibilidade × performance × qualidade |
| **DRE** | Demonstração do Resultado do Exercício |
| **Pipeline / Funil** | Oportunidades de venda por estágio |
| **Roadmap** | Linha do tempo de entregas planejadas |
